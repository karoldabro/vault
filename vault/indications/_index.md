# vault — Indications (working rules, patterns, standards)

| Slug | Rule | Applies-to |
|------|------|------------|
| [[docs-readme-landing-page]] | README is a landing page (what-it-is + one-line install + attach + commands + links); deep detail lives in linked pages; humanize prose but keep reference tables/code dense | `README.md`, `INSTALL.md`, `vault-guide.md`, `tool-playbook.md` |
| [[shared-vs-stack-persona-factoring]] | Generic critics live once in `_shared/`; stack packs compose via `use_shared` + overlays | `personas/**` |
| [[testing-persona-group]] | Testing critics = group in `_shared/testing/`; one AI-failure cluster + one real analyzer per lens; selected on test-touching changes | `personas/_shared/testing/**`, `personas/_resolution.md` |
| [[business-persona-family]] | Business packs are opt-in lenses grounded in installed skills; numbers route to `business/data-evidence`; multi-pack seating keeps one architect seat | `personas/{sales,seo,support,business,startup-eval,marketing}.md`, `personas/_shared/business/**`, `personas/_resolution.md` |
| [[tools-suggestions-not-rules]] | Tool guidance is suggestion not gate — Claude auto-selects; cost hierarchy is a default; only safety notes (e.g. guarded `$HOME` deletes) stay firm | `tool-playbook.md`, `commands/**`, `VAULT.md` `tools` |
| [[critique-loop-stop-conditions]] | Loops stop on round cap or no-new-confirmed-blockers, never on approval alone | `commands/v-team/steps/**` |
| [[confirmed-vs-advisory-findings]] | A finding blocks only when tool-confirmed; unbacked = advisory | `personas/**`, `commands/v-team/steps/**` |
| [[packs-detect-not-assume]] | Packs detect the project's stack/state approach; never hardcode a library | `personas/<stack>.md` |
| [[installer-dry-run-seam]] | Installer side-effects go through a dry-run-able `run()` seam; offline tests assert the transcript, e2e proves the real install | `setup.sh`, `lib/installers.sh`, `tests/**` |
| [[per-user-installer-no-sudo]] | Installer runs as the user, escalates internally for apt only; refuse `sudo` invocation (`$SUDO_USER` set), accept interactive sudo | `setup.sh`, `lib/installers.sh`, `bin/*.sh` |
| [[light-command-siblings]] | Light command variants are single-file, no approval gate; `/v-ask` hard read-only, `/v-do` guarded by scope; escalate up the `/v-ask`→`/v-do`→`/v-work`→`/v-team` ladder | `commands/v-ask.md`, `commands/v-do.md` |
| [[automated-cr-safety]] | PR-review automation: untrusted-input + verdict-from-grounding-gate, secret redaction, host-scoped creds, non-bypassable first-post gate, stable fingerprint, never-commit | `commands/v-cr/**`, `lib/forge-detect.sh`, `lib/cr-helpers.sh` |
| [[sandboxed-cr-safety]] | Executing untrusted PR code: framework-owned isolation envelope (never from repo), no-egress-at-execution, runtime output is untrusted, guarded throwaway-clone cleanup, attribution-aware test gate | `commands/v-cr/sandbox.md`, `lib/cr-sandbox.sh`, `commands/v-cr/**` |
| [[verify-plugin-marketplace-qualifier]] | Plugin install id is `<plugin>@<marketplace-name>` from `marketplace.json` `name` — never the repo owner/path; verify before wiring | `.claude-plugin/marketplace.json`, `README.md`, `commands/v-plugin.md`, `bin/vault-plugin.sh` |
| [[cr-panel-spawn-and-visibility]] | Panel must really spawn one Agent per critic (inlined = non-conformant, prove via `Spawned:`); summary must surface coverage + test posture + comment brevity | `commands/_shared/critic-panel.md`, `commands/v-cr/steps/03-review.md` |
| [[artifact-has-a-named-consumer]] | Every artifact a plan creates names who asks for it, who writes it, who reads it, and what happens when it is absent; `consumer` holds a guaranteed PROPOSE seat and proves a handoff by simulating it | `templates/plan.md`, `personas/_shared/consumer.md`, `personas/_resolution.md`, `commands/v-{team,work}/steps/03-propose*.md`, `bin/doc-lint.sh` |
| [[enforced-not-just-stated]] | A stated threshold or "mechanical" check must name the function computing it and ship a test proven to fail without it | `commands/**/steps/*.md`, `commands/_shared/*.md`, `lib/*.sh`, `bin/doc-lint.sh`, `tests/unit/*.bats` |
| [[cr-delivery-verification]] | Summary posts first and is read back; every comment is verified on the forge by fingerprint; coverage is recorded durably. Never print a count the run did not verify | `commands/v-cr/steps/04-post.md`, `05-capture.md`, `lib/cr-helpers.sh` |
| [[capture-behaviors-test-shaped]] | Capture business logic as test-shaped `## Behaviors & rules` (precondition → expected [; edge]); durable in feature, deltas in session; omit when none; established not aspirational | `templates/session.md`, `templates/feature.md`, `commands/v-capture.md` |
| [[requirements-spec-vs-established]] | `requirements/` holds aspirational REQ-NN specs; `features/` holds the established form promoted at capture. Never write aspirational rules into `features/` | `commands/v-pm/steps/**`, `commands/v-capture.md`, `commands/v-team/steps/{00,03,04}`, `templates/_features/requirements.md` |
| [[generators-emit-critics-confirm]] | Test-design generators emit pre-impl (no analyzer, never on the panel); critics confirm post-impl (bound analyzer, own the vote); all dossier confirmation in EXECUTE | `personas/_shared/testing/design/**`, `commands/v-team/steps/{03,04}-*.md` |
| [[propose-front-gates]] | PROPOSE opens with clarify, then external research — understand and ground before planning. A fork with no safe default always waits for the operator | `commands/v-work/steps/03-propose.md`, `commands/v-team/steps/03-propose-loop.md`, `commands/v-work/steps/01-analyze.md`, `tool-playbook.md` |
| [[cross-project-conversation-workspace]] | Coordinate multi-project sessions through a shared file-based conversation: state in the filename, pull pickup plus a push `status` surface, contract drift checked deterministically | `commands/v-pm.md`, `commands/v-pm/steps/**`, `commands/v-team/steps/00-feature-pickup.md`, `templates/_features/**`, `vault-guide.md` §13 |
| [[user-facing-communication]] | `_shared/communication.md` governs every user-facing line — bind it, never duplicate it. Decision to the terminal, design to the artifact; `Impact` at every gate; omitting empty fields cuts good news, never a warning | `commands/_shared/communication.md`, `output-styles/director.md`, `commands/v-*.md`, all `## Required output` step files, `install.sh` |
| [[document-writing-standard]] | `_shared/document-standard.md` governs every file a command writes — bind it, never duplicate it. Mixing two of its three classes in one file is the defect; shortening deletes narrative, never constraints | `commands/_shared/document-standard.md`, `bin/doc-lint.sh`, `lib/doc-lint-patterns.tsv`, `templates/{plan,trail}.md`, `commands/v-reconcile.md` |
| [[gate-prompts-on-stdin-tty]] | Gate interactive prompts on `[ -t 0 ]` before reading `/dev/tty` — a piped run (`curl \| bash`, CI, bats) has a terminal but no answerer and would hang; the non-interactive branch must be the conservative one, and testing the real prompt needs a pty (`script -qec`) | `setup.sh`, `install.sh`, `bin/*.sh`, `lib/installers.sh` |
| [[guard-home-derived-deletes]] | Never `rm -rf` a `$HOME`-derived path unguarded — `set -u` does NOT catch an empty `HOME`, so `"${HOME}/.x"` becomes `/.x`; use `safe_rm_under_home`, and guard overridable roots (`VAULT_HOME`) on being absolute with a real parent | `bin/*.sh`, `lib/installers.sh` |
| [[vault-git-never-raw]] | Never raw `git` against a vault — call `bin/vault-sync.sh` and branch on its exit code; sync never halts the lifecycle or blocks a capture; no `git init`, no `git add -A`/`.`, no conflict resolution on the user's behalf | `bin/vault-sync.sh`, `commands/_shared/vault-sync.md`, `commands/v-{work,capture,do,pm}*`, `tests/**/vault-sync.bats` |
| [[hooks-never-fail-their-host]] | A shipped hook exits 0 on every path and never blocks a turn: never exit 2 from `Stop`, guard every `source` inside an `if`, validate what reaches a filename, keep linking separate from switching on | `scripts/*-hook.sh`, `lib/hook-common.sh`, `hooks/hooks.json`, `install.sh` |
| [[rules-the-model-can-check]] | Write a rule the model can decide from the text it is writing; a rule needing a count gets a hook or is deleted. Grammar is not the lever; score a rule before cutting it | `commands/**/*.md`, `commands/_shared/*.md`, `hooks/hooks.json`, `bin/rule-audit.sh` |
| [[campaign-evidence-from-the-running-system]] | A campaign verdict cites a run, every case carries an injection designed before it runs, the fixer never verifies its own fix, and the operator names the disposable stack in words | `commands/v-loop.md`, `commands/v-loop/campaign-rules.md`, `templates/campaign/**`, `prompts/on-device-e2e-campaign.md` |
| [[unreadable-is-not-no]] | A check separates "the answer is no" (exit 1) from "I could not read the question" (exit 2); a reader shared by two callers returns "cannot say" and each caller picks its own default | `bin/gate.sh`, `bin/*.sh`, `lib/*.sh`, `commands/**/steps/*.md`, `tests/unit/*.bats` |
| [[rules-routed-not-recalled]] | Compute which rules a change can break, assign each to a reviewer, and print how many were decided; a verdict counts only when a tool resolves the line it cites | `lib/cr-helpers.sh`, `commands/v-cr/steps/**`, `commands/_shared/critic-panel.md`, `bin/indication-route-audit.sh` |
| [[checks-answer-the-same-everywhere]] | A check gives the same answer on every shell, awk and file size: `grep -m1` not `\| head -1`, capture before matching, no dynamic awk regex, `grep -qF --` before a flag-shaped pattern | `checks/*.sh`, `bin/*.sh`, `lib/*.sh`, `scripts/*-hook.sh`, `tests/**/*.bats` |
| [[plugin-extension-never-aborts-host]] | A plugin point runs as a child process through its own shebang with stdin closed; exit 1 declined, above 1 could not run; every call status-guarded; the host always exits 0 | `lib/plugin-registry.sh`, `bin/vault-plugin.sh`, `bin/vault-init.sh`, `bin/gate.sh`, `templates/plugin/**` |
| [[plans-are-build-orders]] | A `plans/*.md` in a repo you are about to change is the thing to build, not background; `status: proposed` means unbuilt, not unavailable; grep its work items before writing a file that may already ship | `commands/v-work/steps/02-load-context.md`, `commands/v-team/steps/**`, `commands/v-do.md` |
| [[bats-negative-assertions-need-a-function]] | A bare `! grep` in the middle of a bats test never fails it; assert absence with a function that returns 1 | `tests/unit/*.bats` |
| [[architecture-before-code]] | In a repo with an `arch_profile` other than `none`, write no work item until `bin/gate.sh arch <plan>` exits 0; the spec states structure and work items follow | `commands/v-team/steps/03-propose-loop.md`, `commands/v-team.md`, `commands/_shared/architecture-spec.md`, `bin/gate.sh` |
| [[git-in-an-untrusted-repo-runs-its-code]] | Call git on a repo under review only through `probe_git`; a repo's fsmonitor, filter, lazy-fetch and hook commands otherwise run | `lib/probe-scope.sh`, `bin/probe.sh`, scripts that run git in a reviewed repo |

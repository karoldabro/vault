Task

A multi-session plan is approved only when three things hold. Every case of the operator's goal has an owning session. Its runtime fits the operator's limit. Its sessions are not split smaller than the repo needs. When the plan closes, the goal command runs, and each failing case becomes a new session.

Two sessions. S1 builds the planning-time checks: the goal table, the goal-case ownership script, the runtime limit, the deferral-phrase block, the session-merge rule, and the goal-fit reviewer. S2 builds the run-time checks: the first and last goal runs, the case status flips, the scope-change recheck, and the gap loop.

Repairs vault/reports/2026-11-07-1400-plans-pass-gates-without-reaching-the-goal.md and the over-split sessions of ~/vault/givore/plans/e2e-coverage-1160/plan.md.

Needs your decision

  • needs the operator: after S2 ships, run one /v-pm plan and confirm its approval block prints the goal line with owned 100%. That closes the report.
  • needs the operator: 16 existing master plans lack goal_fit: required and get one warning line. Add the key to a plan to put it under the checks.
  • needs the operator: set session_max_changes in VAULT.md of a repo whose small changes span many files, such as givore.com. The default is 15.

Interfaces

  • bin/gate.sh.goal(plan: path): exit 0 ok or silent, 1 refused, 2 unreadable
  • bin/gate.sh.goal baseline(plan: path): exit 0 recorded or note, 1 first run passed or no script
  • bin/gate.sh.goal close(plan: path, session: string, cases: string): exit 0 cases marked pass, 1 on a foreign flip or short ownership
  • bin/gate.sh.goal last(plan: path): `goal: last run passed`, `failed`, `not run`, `waits` or `already running`; exit 0
  • bin/gate.sh.goal failing(plan: path): failing case ids from the saved log; exit 1 without a log
  • bin/goal-trace.sh.trace(plan: path): `owned N/M` and unowned rows; exit 0 full, 1 short, 2 unreadable
  • bin/pm-plan.sh.gap(plan: path, cases: string): one row per repo appended, gap_rounds bumped; exit 1 at 3
  • lib/goal-check.sh.cmd_goal(plan: path): `REFUSED goal <plan>:` lines, `goal: ok <plan>`, throws die on unreadable file
  • lib/master-check.sh.master_resolve(plan: path, session_of: string): master path on stdout, 1 when unresolved

Interfaces

  • bin/change-map.sh.build(repo: path, base: ref, head: ref): six-field rows of the plan's Map row contract on stdout, then one `map-status` line; exit 0, throws exit 2: repo is not a git repo, or a ref is not a commit
  • bin/change-map.sh.slice(map: path, persona: path, paths: path): the `map-status` line, then the rows whose relation the persona's `map:` key lists, cut at `VCR_SLICE_BYTES` with a `withheld: <n> rows` line; exit 0, throws exit 2: the map is unreadable, or the persona has no `map:` key
  • bin/change-map.sh.status(map: path): `map_status:` and one `map_<relation>:` line per relation for the coverage block; exit 0, throws exit 2: the map has no `map-status` line
  • personas/_shared/review/<seat>.md.frontmatter(id: string, base_agent: string, map: list): the persona block and its map relations

Data flow

flowchart LR
    A["review step"] -->|"posture: string, repo: path, base: string"| B["bin/probe-panel.sh"]
    B -->|"flags: string"| C["bin/probe.sh"]
    C -->|"finding rows: tsv, status lines, exit code"| B
    B -->|"changed files: nul"| D["lib/probe-scope.sh"]
    B -->|"fenced block: text, exit code"| A
    A -->|"block: text"| E["critic prompt"]
    E -->|"check: probe id file:line"| F["bin/probe-panel.sh cited"]

Interfaces

  • probe-panel.sh.run(posture: string, repo: path, base: string, out: path, paths: path): the fenced block, operator.txt when incomplete, exit code 0 or 2, throws exit 2
  • probe-panel.sh.cited(out: path, probe: string, file: path, line: int): confirmed or advisory with exit 0, none with exit 1, throws exit 2
  • indication-route-audit.sh.audit(index: path, changed: path, repo: path): unroutable, unknown-probe and unchecked-probe lines, exit 0 or 1, throws exit 2

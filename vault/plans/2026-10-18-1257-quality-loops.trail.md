Record class, so chronology belongs here and nowhere else. Its contract document is

## Decisions & trade-offs

| decision | alternative rejected | why it lost |
|---|---|---|
| plugin point `check` supplies the tools | three new `VAULT.md` keys (`static_analysis_command`, `coverage_command`, `mutation_command`) required by `gate.sh config` | ~90 onboarded repos would be refused at session start; vault-quality-gates already measures all three |
| plugin side built in its own session | build `extend/check.sh` here | another repo with its own gate and contract; the point must exist first |
| label every survivor | fixed mutation score, e.g. covered MSI 70 | unkillable mutants make a fixed score block forever or invite fake tests |
| changed-line floor 80 | repo-wide floor 80 | refuses every change in a repo below 80 today |
| keep the id `quality` | rename to `simplicity` | rewrites every pack overlay for no behaviour change |
| new generators, no new critics | security and API test critics | ADR-006 requires a distinct critic failure cluster; writing tests is generation (ADR-011) |

## Rejected / deferred

- Research, kept for audit:
  - diff-cover (https://pypi.org/project/diff-cover/) — changed-line coverage from Cobertura, Clover, JaCoCo or LCOV; `--fail-under=80` sets the exit.
  - Petrović et al., Practical Mutation Testing at Scale (https://arxiv.org/abs/2102.11378) — mutate changed code only and surface survivors in review; neither a score nor all survivors is actionable.
  - Infection (https://infection.github.io/) — `--git-diff-lines` limits mutation to changed lines; `--git-diff-base` was not confirmed by search, so the plugin session checks `infection --help`.
- Merging `test-behaviorist` and `test-harness-critic` was proposed in conversation and deferred for lack of overlap evidence.
- Round 2: 1 combined reviewer, 12 findings, 7 confirmed MAJOR, all applied after the round cap; nobody re-reviewed the round-2 fixes. Round-1 items reopened: harn-6, arch-2, cons-1, harn-2, skep-4.
- Test design dossier written by the drafter; the `(f2)` generators were not spawned.

v-pm-planning-loop — plan

Task

Rework /v-pm into a read-only planner. It refuses to plan until the operator states success criteria. It reads the vault and the code of every repo in scope, researches prior art, and drafts an architecture plan. A parallel panel of planning reviewers critiques the draft until it converges. The output is one normalized plan. Its Sessions table names the repo and command of each session and gives a run order in parallel waves. Each session has one brief with a ready-to-paste shell line. The reviewers live in a reusable group, personas/_shared/planning/.

Interfaces

  • bin/pm-plan.sh.check(plan: path): exit 0, or exit 1 with one line per defect, throws exit 2 unreadable plan
  • bin/pm-plan.sh.order(plan: path): one line per session: wave, id, status, readiness, repo, brief, throws exit 1 on a depends cycle
  • bin/pm-plan.sh.set(plan: path, id: string, assignments: string): rewrites one row under flock, throws exit 1 unknown id or column
  • commands/_shared/feature-pickup.md.step 0(locator: string): the brief goal as the task restatement, throws ends the session when the row is not todo runnable

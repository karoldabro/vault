# 2026-09-21-1130-probe-kit-core — process record

Record class. Its contract document is `vault/plans/2026-09-21-1130-probe-kit-core.md`.

## Decisions & trade-offs

| decision | alternative rejected | why it lost |
|---|---|---|
| Registry rows only for tools whose flag was verified and whose real output a parser test consumes | one row per tool in the catalog | 7 of 12 claims were wrong or partly wrong; a row with an unverified flag produces false grounding |
| Native probes in bash and POSIX awk | Python scripts | the framework is bash, the test container has BusyBox awk, and no Python file exists here |
| Repo registry rows always count as `executes-repo-code: yes` | trust the cell | a pull request can add a row that claims `no` |
| `diff` is a scope of `run`, so one script has one row | one row per stage, or a comma list in `stage` | two rows copy every cell, and C-3 names single values |
| `scale` prints size and the largest fitting cost class | a token or time estimate | nothing measures either yet; session S5 measures |
| claude validate parsed with `jq` | awk over the JSON | the report is nested; awk over pretty-printed JSON breaks on one reformatting |

## Verification of the 12 tool claims

Sources are in `vault/research/probe-tool-verification.md` once W-1 lands. Working notes: agents wrote `verify-A.md`, `verify-B.md` and `verify-C.md` in the session scratchpad; the main session re-opened the Atlas and tbls sources and ran lizard, typos and ast-grep itself.

| claim | verdict | what changed |
|-------|---------|--------------|
| Atlas lint free tier | refuted | `atlas migrate lint` is Pro only since v0.38 and needs `atlas login` |
| DCM licence and JSON flag | partly | JSON reporter exists; the licence is commercial with a 50k line free tier |
| PHPArkitect `--format=json` | verified | formats `text`, `json`, `gitlab`; package `phparkitect/phparkitect` |
| tbls `lint --format json` | refuted | `tbls lint` has no format flag; output is text, exit 1 on violations |
| PHPMD empty catch | partly | rule is `EmptyCatchBlock` in the `design` ruleset |
| Semgrep Dart and Vue | partly | Dart works; Vue support was removed in Semgrep 1.93.0 |
| ast-grep Dart and Vue | refuted | Dart is not built in and Vue is an invalid `--lang` |
| lizard `--json` | refuted | flags are `--csv`, `-X`, `-H` |
| PMD 7 CPD flags | partly | no `json` format; `xml`, `csv`, `markdown`; exit 4 on duplicates |
| typos on PyPI | verified | PyPI project `typos`; `--format json` prints one object per line |
| Qlty offline | partly | free, SARIF output; needs network on first run; no Dart or Vue |
| `claude plugin validate` | verified | `--json`, `--strict`; exit 0 or 1 |

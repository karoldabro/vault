# 2026-06-19-1106-v-cr-command — process record

Contract document: `vault/plans/2026-06-19-1106-v-cr-command.md`.

## Decisions & trade-offs

| decision | alternative rejected | why it lost |
|---|---|---|
| Extract the single-pass panel into `commands/_shared/critic-panel.md` | Reuse `commands/v-team/steps/04-execute-loop.md` §5.3 directly | §5.3 is a fix-and-reloop; 3 of its 5 steps do not apply to a static remote PR |
| Fingerprint `sha256(file:rule:code-hash)`, comments generated at temperature 0 | `sha256(file:rule:msg)` | LLM message text varies per run, so re-review posts duplicates instead of skipping |
| Non-bypassable first-post gate per `(repo, PR)`, hard cap of 10 inline comments, `--unpost` | One coarse approval gate over the whole comment set, `--post` skips it | One gate over N comments gives the operator no undo and a large blast radius |
| Resolve the persona pack by base-repo slug, fail loudly when none resolves | Resolve against the local checkout (cwd) | The local tree need not be the reviewed repo, so the wrong pack loads silently |
| Extract task keys from branch name and PR title only, against a project-key allowlist | Regex over branch, title, body and diff | `UTF-8`, `SHA-256` and `#404` match the key shapes and ground the review in the wrong issue |
